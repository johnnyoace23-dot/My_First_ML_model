# 🎓 Student Placement Prediction using Logistic Regression

This is my **first Machine Learning project** built using Python and Scikit-learn. The project predicts whether a student is likely to be placed based on **CGPA** and **IQ** using a Logistic Regression classification model.

## 📌 Project Overview

This project demonstrates the complete beginner-friendly Machine Learning workflow:
- Data loading and exploration
- Data visualization
- Train-test split
- Feature scaling with `StandardScaler`
- Logistic Regression model training
- Model evaluation using accuracy score
- Decision boundary visualization with MLxtend

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- MLxtend

## 📂 Dataset Features

| Feature | Description |
|---------|-------------|
| `cgpa` | Student's CGPA |
| `iq` | Student's IQ score |
| `placement` | Target variable (0 = Not Placed, 1 = Placed) |

## 🚀 ML Workflow

1. Import and explore the dataset.
2. Visualize the data using scatter plots.
3. Split the dataset into training and testing sets.
4. Standardize features using `StandardScaler`.
5. Train a `LogisticRegression` model.
6. Predict placement on test data.
7. Evaluate model accuracy.
8. Visualize the decision boundary.

## 📈 Results

The model successfully classifies students into placed and not placed categories and visualizes how Logistic Regression separates both classes using a decision boundary.
